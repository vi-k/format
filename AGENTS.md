# Инструкции для агента

Точка входа для новой сессии, общая для всех агентов: Codex читает этот
файл сам, Claude Code — через `@AGENTS.md` в `CLAUDE.md` рядом.

Здесь намеренно нет ни состояния проекта, ни подробностей правил. Всё
это живёт в `docs/` и меняется вместе с проектом; файл, который бы это
пересказывал, разошёлся бы с оригиналом так же, как разошлись
дизайн-документы с кодом (разбор L17). Здесь — только то, что не зависит
от состояния и должно действовать до того, как что-либо прочитано.

## С чего начать

**Прочитать два файла целиком, до первого действия:**

- `docs/handoff.md` — состояние проекта и раздел `## Что открыто`.
  Первый пункт того раздела и есть следующее дело, если пользователь не
  сказал иначе. Документ короткий и переписывается каждую сессию.
- `docs/conventions.md` — правила работы, полный список проверок перед
  коммитом, порядок публикации и накопленные ловушки. Меняется редко.

Рядом с ними: `docs/architecture.md` — устойчивое устройство кода,
`docs/backlog.md` — бэклог владельца, `docs/records/` — спеки, планы,
отчёты и ревью. Здесь они не пересказываются, потому что и файлы, и их
состояние меняются.

## Что действует с первого хода

Семь обязанностей. Их параметры и обоснования — в `docs/conventions.md`;
здесь только сами обязанности, потому что нарушение любой из них дорого
и необратимо.

- **Прогонять весь список проверок перед коммитом, а не подмножество.**
  Список в `docs/conventions.md`, раздел `## Как проверить всё`.
  Node-прогон и сборка архива ловят то, чего не ловит `dart test`.
- **Нет performance GREEN — нет коммита.** Правку, заявленную как
  ускорение, без замера не коммитить; не подтвердилось — откатить, а
  замер записать. Решает **локальный** замер, а не гейт: методика в
  `docs/conventions.md`, раздел `## Ловушки и знания`. Эталон гейта
  коммит не блокирует — он переснимается отдельно и не всегда сразу,
  разбор там же.
- **Мержить прямо в `main`, без PR.** Проверки это не отменяет.
- **Публикация — связка целиком, а не отдельные шаги.** Коммит релиза,
  тег `vX.Y.Z` на нём, push, `dart pub publish` в обоих пакетах и GitHub
  Release по тому же тегу — один заход и подряд, ни одну часть по
  отдельности. Успешный `dart pub publish` — ещё не конец: тег создаётся
  на том коммите, из которого собран опубликованный архив, и оба
  удалённых объекта проверяются; без них релиз не завершён. Подготовка к
  публикации — обычные правки в дереве, её можно делать свободно.
  Разбор — в `docs/conventions.md`, раздел `## Публикация`.
- **Разрешение на публикацию — только явное и только на эту связку.** Оно
  не переносится на следующий релиз, не наследуется от прошлого раза и не
  выводится из готовности: ни «всё готово к публикации», ни пройденный
  чеклист, ни зелёный CI разрешением не являются. Есть в сообщении
  владельца хоть что-то ещё, кроме публикации, — **не запускать ничего из
  связки и не спрашивать**: сделать остальную работу и отказать в
  публикации, назвав условие — отдельный запрос владельца, состоящий
  только из просьбы опубликовать. Сомневаешься — не публиковать: отказ
  стоит одного сообщения, ошибка стоит номера версии.
- **Не коммитить чужие правки вместе со своими.** `docs/backlog.md`
  наполняет владелец, и незавершённые правки в нём — чужие:
  `git add -A ':(exclude)docs/backlog.md'`, запуская `git add` из корня
  репозитория, иначе исключение разрешится относительно текущего каталога
  и не сработает. Исключение одно: **исполненный пункт вычёркивает сам
  тот, кто его исполнил** — отдельным `git add docs/backlog.md` в том же
  коммите, что и работа по нему.
- **Не удалять и не переписывать молча пункты реестра вердиктов.** У
  пункта либо стоит вердикт с обоснованием, либо он открыт.

Документы проекта пишутся по-русски, код и комментарии в коде — на
английском.

## В конце сессии

- Обновить `docs/handoff.md`: строку `Статус:` с датой, состояние и
  список открытого. Handoff, отставший от репозитория, ломает механизм
  восстановления целиком.
- **Историю сделанного писать не в handoff, а в `docs/records/`** —
  отдельным файлом `YYYY-MM-DD[N]-<тема>-report.md` с шапкой. В handoff
  идёт только то, что верно на сейчас.
