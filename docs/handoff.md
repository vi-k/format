**Ветка `main`, дерево чистое.** Мержим прямо в `main`, без PR.

**Опубликовано.** `format 4.0.0` — на pub.dev с 2026-08-15, собран из
коммита `8bbddb8`; тег `v4.0.0` и GitHub Release проверены на удалённом.
`format 3.0.0` от 2026-08-14 ретрактирована в тот же день — **отменить

не переиспользуется в любом случае. `format_intl` — `1.0.1`, его
ограничение на `format` — `>=3.0.0 <5.0.0`: адаптер реализует только
`NumberLocale`, которой мажор не касался, и работает на обоих. Под Flutter
адаптер требует 3.32.0 и новее: `flutter_localizations` в 3.29.x пинит
`intl 0.19.0`, а здесь `^0.20.2`. Сам `format` доходит до 3.29.2 — первого
Flutter с Dart 3.7.2. Разбор и проверки — в
`docs/records/2026-08-17[1]-flutter-compatibility-report.md`.

Мажорной версию сделало одно изменение — типизированные предикаты
расширений (`canFormat`, `canLookup`, `canRepresent` принимают `T`).
Почему мажор, а не минор, разобрано исполнением в
`docs/records/2026-08-15[4]-format-reference-and-4-0-0-report.md`.

**SDK.** Внутренние wasm-host'ы, форматтер и primary jobs — на текущем
Dart stable (3.13.0). Минимальный поддерживаемый SDK — **3.6.0**
(с 2026-08-18, было 3.7.2), у него своя job. Исходники при этом остаются
в стиле форматтера 3.7: `dart format --language-version=3.7` везде, где
он зовётся, — разбор в `docs/conventions.md`, раздел
`## Ловушки и знания`.

**Не выпущено.** В `main` лежат три изменения. Первое — понижение пола
SDK до `^3.6.0` в обоих пакетах: `format` доходит теперь до Flutter
3.27.0. Второе — ограничение `intl` в адаптере расширено до
`>=0.19.0 <0.21.0`, так что и он ставится с Flutter 3.27.0, а не с
3.32.0; вердикт `2026-08-17[1]` этим пересмотрен, разбор — в
`docs/records/2026-08-18[2]-intl-constraint-report.md`. Третье — правка
дефекта dart2wasm: все конверсии
— `!s`, `!r` и `!a` — бросали `UnsupportedConversionException` на всех
SDK с 3.6.0 по 3.9.0, то есть на всём объявленном диапазоне ниже

`String?` с `case null`, который эти версии компилируют неверно; в
`applyConversion` null-ветка теперь отвечена стражем до switch'а. Запись
в `CHANGELOG.md` стоит под `## Unreleased`, версия в pubspec не поднята.

`docs/records/2026-08-18[1]-wasm-null-switch-and-sdk-floor-report.md`.

## Что открыто

Активной implementation-работы нет. Открыт один пункт — и он про релиз.

### Релиз

- **Выпустить 4.1.0.** В `main` лежат понижение пола SDK и правка
  конверсий под dart2wasm, обе не опубликованы. Минор, а не патч:
  расширение диапазона SDK — это новая совместимость, а не только
  починка. Обряд обычный — бамп версий в обоих пакетах,
  `## Unreleased` → `## 4.1.0` и `## 1.1.0`, публикация, теги, GitHub
  Release, проверка обоих удалённых объектов. Цена расширенного `intl`
  задокументирована в README адаптера: четыре локали из 119 несут разные
  символы по диапазону, и три из четырёх расходились уже внутри
  `^0.20.2`.

### Замеренные решения по кэшу

Пул `CharSink`'ов **отклонён замером 2026-08-13**, константы адаптивной
политики кэша **подтверждены замером** тогда же и не изменились. Разбор
обоих — в
`docs/records/2026-08-13[3]-third-review-and-cache-policy-report.md`.
Открытыми пунктами они не являются и лежат здесь только как указатель.

### Эталон гейта

Пересъёмка **не требуется прямо сейчас.** После записи в `lib/` легли
три правки — ускорение `c` под JavaScript, типизированные предикаты
расширений и страж null-конверсии. Первая односторонняя, вторая матрицы
не касается: расширений в сценариях нет. Третья идёт через сценарий
`brace.conversion` (`{!s:.2s}`) и **замерена** 2026-08-18: на VM
неотличима (минимумы 184.9 против 184.3 нс, девять перемешанных
прогонов на вариант), под dart2js быстрее исходной формы (145.0 против
147.0 нс). `benchmark/scenarios.dart` после `9143e74` не менялся,
поэтому незнакомых id гейт не встретит.

Правило и его обоснование — в `docs/conventions.md`, раздел
`## Ловушки и знания`, пункт про односторонний эталон.
