## Что открыто

Первые два пункта — решения владельца, а не работа.

### Решения, которых ждёт код

- **Выпускать ли 4.0.1.** Правка `!r`/`!a` под dart2wasm смержена, но не
  опубликована: она меняет поведение на вебе для всех, кто собирает
  пакет на Dart ниже 3.10.0. Обряд обычный — бамп версии,
  `## Unreleased` → `## 4.0.1`, публикация, тег, GitHub Release.
- **Понижать ли пол SDK до `^3.6.0`.** Цена замерена целиком на живых
  SDK: почти всё проходит без правок, платить нужно за форматтер (обход
  — `dart format --language-version=3.7`, diff нулевой), за пять info
  анализатора 3.6 и за неработающий на 3.6 бенчмарк-харнесс. Покупается
  Flutter 3.27.0–3.27.4 и 3.29.0–3.29.1; `format_intl` не выигрывает
  ничего. Подробности и числа — в
  `docs/records/2026-08-18[1]-wasm-null-switch-and-sdk-floor-report.md`.

Активной implementation-работы нет. Ниже — только резервы, которые
никто не начинал, и состояние эталона гейта.

### Резервы производительности, не начатые

- **dtoa прямо в sink** — double-op'ы сперва получают готовое тело
  строкой и только потом отдают его в sink; генерация цифр напрямую
  убрала бы промежуточную строку. Резерв остался, но подешевел и
  сузился: с 2026-08-12 цифры `g`/`e`/пустого типа приходят от
  платформы, то есть промежуточных строк на этом пути теперь две — та,
  что вернула конверсия, и собранное из неё тело, — а не разбор в
  `BigInt`. Убирать имеет смысл вторую; первую без своего dtoa не
  убрать вовсе. Раскладка вокруг тела из этого резерва вычтена: для
  шаблона из одного поля она закрыта 2026-08-13, а там, где полей
  несколько, буфер уже оплачен и писать в него — правильно.
- **`Uint16List(16)` на пустой ёмкости** — программа из одного литерала
  получает `estimatedCapacity == 0` именно чтобы ничего не готовить, и
  всё равно аллоцирует буфер: 6.0 нс из 8.9 нс создания sink'а по
  декомпозиции 2026-08-13. Всплыло при разборе L7 и отложено как
  самостоятельная работа: путь одного литерала уже уходит в режим одной
  строки и буфера не касается, так что выигрыш достанется другим формам
  и его надо мерить отдельно.
- ~~Пул `CharSink`'ов~~ — **отклонён замером 2026-08-13**, разбор в
  `docs/records/2026-08-13[3]-third-review-and-cache-policy-report.md`.
- ~~Константы адаптивной политики кэша~~ — **подтверждены замером
  2026-08-13**, значения не изменились; разбор там же.

### Эталон гейта

Пересъёмка **не требуется прямо сейчас.** После записи в `lib/` легли
две правки — ускорение `c` под JavaScript и типизированные предикаты
расширений. Первая односторонняя, вторая матрицы не касается:
расширений в сценариях нет. `benchmark/scenarios.dart` после `9143e74`
не менялся, поэтому незнакомых id гейт не встретит.

Правило и его обоснование — в `docs/conventions.md`, раздел
`## Ловушки и знания`, пункт про односторонний эталон.
